# Task 1 - HTML Structure and Basic Server Interaction
## Objective
The objective of this task is to create an HTML structure with
user-input forms and connect the form to a basic Node.js server.
## What I Built
I created a Student Registration Web Application.
The application allows a user to enter:
- Name
- Email
- Course
The submitted form data is processed by an Express server and
displayed using EJS server-side rendering.
## Technologies Used
- HTML
- CSS
- Node.js
- Express.js
- EJS
## Main Features
- Student registration form
- Form submission
- Express server
- Server-side endpoint
- EJS server-side rendering
## Output
The application displays a student registration form.
After submitting valid information, the application displays
the submitted student details and a registration-success message.
