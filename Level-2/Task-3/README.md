# Task 3 - Advanced CSS Styling & Responsive Design
This task demonstrates advanced CSS styling, responsive design,
CSS transitions and animations, complex layouts, and Bootstrap.
## Objectives
- Create a responsive web page.
- Use advanced CSS styling.
- Add CSS transitions and hover effects.
- Create a responsive layout using Bootstrap.
- Make the page work on desktop and mobile screens.
## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
## Features
- Responsive navigation bar
- Responsive hero section
- Bootstrap grid layout
- Interactive cards
- Hover animations
- Mobile-friendly design
